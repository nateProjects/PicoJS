PicoDiver — picoJS port

Arrows move · X easy mode from title · Z arcade (hard) mode. Ported from picodiver2.p8; sound (sfx) isn't implemented yet — see picodiver.js header for the full list of what's skipped. Palette swaps (pal) are now live: watch the title-screen ship recolour, and the dolphin turn grey once you've played arcade mode.

Works straight from disk — just double-click this file, no local server needed. (Earlier picoJS versions read pixel-perfect collision back out of a canvas, which browsers block for file:// pages; this port now feeds sget() pre-parsed pixel data directly via picodiver-data.js, so that restriction doesn't apply here. If picoJS ever fails to build that data, the title screen will show a warning rather than silently breaking collision.)
