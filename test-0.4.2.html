What to verify

Converter pipeline

  • tests/sample-mapdata.js exists and is loaded before the game script
  • No map PNG is referenced — mapData is supplied instead
  • Debug panel shows source sample.p8 -> sample-mapdata.js
  • Log line map 128x32 (from sample.p8) on boot
  • Version reads 0.4.2 in the HUD

Gameplay (regression from 0.4.1)

  • Bordered room renders in the top-left 16×16 tiles
  • Walls block movement; can’t leave the room
  • Walking onto a coin clears it and bumps score
  • Z stamps a coin, re-entering the tile picks it up
  • Hold X → coins vanish, walls remain

Regenerating the data

  • Edit tests/sample.p8, then run node tools/p8-to-js.js tests/sample.p8 tests/sample-mapdata.js and reload this page
