picoJS 0.4.8 — bitmap fonts

X cycles the default font between pico8, system, and the custom big font. No spritesheet needed — everything here is text and primitives.

What to verify

Default bitmap font

  • Text is crisp, blocky pixels — no anti-aliased/blurry edges, even before any CSS scaling
  • Compare directly against the "always system" line below it: same string, visibly softer/anti-aliased

X cycling picoJS.setFont()

  • "default (...)" line's rendering changes as you press X — pico8 crisp pixels vs. system's anti-aliased font
  • The three "always ..." lines below never change — they pass an explicit font as print()'s 5th argument, proving a per-call override coexists with the global default

Custom font (registerFont)

  • "BIG FONT" renders in a chunky 8x8 custom font — proves registerFont() isn't hardcoded to the built-in 4x6 cell size
  • Only B/I/G/F/O/N/T + space were hand-authored; every other code in its registered range safely renders blank rather than garbage
